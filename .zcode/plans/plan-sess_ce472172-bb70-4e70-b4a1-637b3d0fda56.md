# bigAagents 增量开发计划：新闻采集 + 统一持久化 + 相似历史日

## 前置探测（开工第一步，决定方案细节）
实测 akshare 三源可达性：`stock_info_global_cls`（财联社电报）/ `stock_info_global_sina`（新浪7x24）/ `stock_info_global_ths`（同花顺）；不可达的源剔除，可达的进降级链。

## Phase N1：财经新闻采集系统（约 2 天）
1. `db/store.py` 统一存储层（SQLite，同 portfolio.db 实例）：新建 `news_items` 表（id/标题/内容/来源/发布时间/关联股票/情绪标签）、`chat_logs`、`daily_features` 表
2. `data/news_feed.py`：三源降级链拉取快讯（akshare）→ 标题去重（hash）→ 落库 → 个股关联（标题匹配自选股名称/代码 + 六大板块关键词）
3. 调度：交易日每小时拉取一次（scheduler 新任务）
4. 接线三处消费：
   - AI 助手新增工具 `tool_latest_news(keyword可选)`（最近 N 条/按股票过滤）
   - 复盘 Agent 新增「今日要闻」章节（当日新闻聚类摘要）
   - screener 舆情因子从占位分改为真实"新闻正面率"（news.py 的第三方 API 依赖退役）
5. 测试：mock akshare 的解析/去重/关联/降级用例

## Phase N2：持久化统一（约 1 天）
1. 回测报告元数据、daily_picks 结果落库（JSON 文件保留，看板/兼容不动）
2. 对话日志落 `chat_logs`（每轮 user/assistant + 工具名 + token 用量）
3. 数据保留策略：news_items 保留 180 天，chat_logs 保留 90 天
4. 配置页新增「数据统计」卡（各表行数/最新时间）

## Phase N3：相似历史日（约 2-3 天）
1. `data/similar_days.py`：
   - 特征构建（纯可回填维度 v1）：日涨跌幅、量比、20日波动率、MA5/10/20/60 相对位置、市场状态分、连涨连跌——约 12-15 维，z-score 归一化
   - 历史回填：指数（上证/深成/创业板）+ 自选股，从腾讯历史K线拉约 8-10 年日K
   - 向量存 `daily_features` 表，检索用 numpy 余弦相似度（毫秒级暴力扫描）
2. 检索输出：top-k 相似日 + **其后 5/20 日上涨概率与平均涨跌幅分布**（关键：给统计分布而非单点预测）
3. Agent 工具 `tool_similar_days(symbol或index, date可选)`，系统提示词注明"输出必须表述为历史统计参考，不是预测"
4. 对话示例："今天上证走势像历史上哪几天？后来怎么样了"；复盘 Agent 附录「历史相似日参考」
5. 测试：特征构建/归一化/检索/分布统计（mock K线数据）

## 验收标准
- 新闻：问 AI"最近有什么影响 XX 的新闻"能返回入库的真实快讯；舆情因子非占位
- 持久化：重启后对话历史/新闻可查；配置页可见各表统计
- 相似日：问"今天像历史上哪天"返回 top-k 相似日+后续表现分布，并明确标注"统计参考非预测"
